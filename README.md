🇮🇩 **Ringkasan singkat:** LeakLens adalah dashboard analitik penjualan untuk UMKM Indonesia. Upload data penjualan dari kasir atau marketplace, lalu AI membersihkan data, menemukan pola yang tidak terlihat sekilas (misalnya pelanggan setia yang tiba-tiba berhenti membeli), dan memberi rekomendasi yang bisa langsung dijalankan besok.

## 💡 Why LeakLens?

More and more Indonesian small businesses are digitizing their sales: cashier apps, GoFood, Shopee, spreadsheets. But having data is not the same as understanding it. Some of the most important patterns are invisible at first glance.

For example: a customer who used to buy every single day has not bought anything in the last 12 days. Nobody scrolling through thousands of rows would notice. LeakLens does, and tells the owner what to do about it.

The goal is simple: give UMKM owners real business decisions, not just charts. LeakLens started at **exploreAItion**, a hackathon hosted by Jagoan Hosting (Indonesia), where our team of three built the first version. We are now developing it into a finished product that can be monetized.

## ✨ Features

- **Customer churn alerts**: detects regular customers who have stopped buying compared to their usual rhythm
- **AI insights**: diagnosis, 3-step action plan, and key-metrics snapshot generated by an LLM
- **Upload CSV / XLSX**: automatic column detection and data cleaning
- **Platform fee detection**: calculates gross vs. net sales per channel (GoFood, Shopee, etc.)
- **Analytics summary**: top SKUs, channel mix, Pareto (80/20) concentration, peak hours
- **Visual analytics**: daily revenue, top products, and peak-hour charts
- **Competitor analysis** (Pro): live market search via Tavily to compare your product with similar ones
- **Export** (Pro): cleaned CSV, Markdown insight, and printable HTML/PDF report
- **Sample data**: try everything instantly without uploading a file

> The app interface is in Bahasa Indonesia.

## 🛠️ Tech Stack

- [Streamlit](https://streamlit.io/): web UI
- [pandas](https://pandas.pydata.org/) / NumPy: data cleaning and analytics
- [Plotly](https://plotly.com/python/): charts
- LLM providers: OpenRouter (default), Groq, OpenAI, or Anthropic
- [Tavily](https://tavily.com/): web search for competitor analysis

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jojoisstudying/leak-lens.git
cd leak-lens
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv

# macOS / Linux
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Set up environment variables

Copy the example file and fill in your own keys:

```bash
cp .env.example .env
```

Then edit `.env`:

```env
# Choose one: openrouter | groq | openai | anthropic
LLM_PROVIDER=openrouter

# Optional: override the default model for your provider
LLM_MODEL=

# Add the key for the provider you chose
OPENROUTER_API_KEY=your_key_here
GROQ_API_KEY=
OPENAI_API_KEY=
ANTHROPIC_API_KEY=

# Required only for the competitor analysis feature
TAVILY_API_KEY=
```

> ⚠️ **Never commit your `.env` file.** It is already listed in `.gitignore`.

### 5. Run the app

```bash
streamlit run app.py
```

Open [http://localhost:8501](http://localhost:8501) in your browser.

## 📖 Usage

1. Upload your sales file (`.csv` or `.xlsx`), or click **🎯 Coba dengan Data Contoh** to use sample data.
2. Review the cleaned data and KPIs.
3. Click **Generate Insight LLM** to get the diagnosis and action plan.
4. Explore the **Visual Analytics** tab for charts.
5. Switch the plan selector to **Pro** to try competitor analysis and exports.

If no API key is configured, the app still runs and falls back to a basic insight mode.

## ☁️ Deploying to Streamlit Cloud

The `.env` file is not deployed. Instead, add your keys under **App → Settings → Secrets**:

```toml
OPENROUTER_API_KEY = "your_key_here"
LLM_PROVIDER = "openrouter"
TAVILY_API_KEY = "your_key_here"
```
